# 快图怀旧版

基于快图浏览（QuickPic）4.5.2 的个人兼容修改版，保留原有相册界面，适配仅支持 64 位进程的安卓设备。非官方项目。

## 下载

前往 [Releases](https://github.com/tiancaiProgramer/quickpic-classic/releases/latest) 下载 **快图怀旧版_4.5.2.apk**。

- 应用名称：快图怀旧版
- 显示版本：4.5.2
- 包名：`com.alensw.PicFolder`
- 最低 Android 版本：Android 7.0（API 24）
- 目标 API：28
- 已测试设备：小米 15 / Android 16 / arm64-v8a

## 功能与调整

- 保留相册、按时间浏览、图片查看和原有基本操作。
- 64 位 Android ART 进程运行，替换旧的 31 个 JNI 接口，不再加载旧 32 位原生库。
- 增加 HEIC / HEIF 格式识别，解码依赖设备系统。
- 识别实况照片中的内嵌视频，或同目录同名的图片与 MOV / MP4。点开照片后在原浏览页静音播放一次，点击 LIVE 可停止或重播。
- 保留局域网快传。
- 修复左侧导航栏尺寸和紫色图标，侧栏保留相册、活动、快传、设置。
- 主页设置和快传只保留左侧入口；无法展开侧栏的查看或选择模式保留原有上下文操作。
- 移除不可用的云备份和添加云账号入口；此前增加的 WebDAV 已移除。

## “活动”视图

“活动”对应 Moments，为本地照片的时间分组视图。默认按自然月归类，有可解析的地点时再按地点细分。优先使用系统媒体库的拍摄时间，缺失时使用文件修改时间，月份边界按手机时区计算。

## 安装与兼容

本发布包与本项目的兼容测试版使用相同签名，可覆盖安装；显示版本恢复为 4.5.2，内部安装编号保留为 99999172。不同签名的原版无法直接覆盖。

需要允许照片、视频和存储访问。快传需要网络与 Wi-Fi 相关权限。

这不是将原 C/C++ 核心重新编译为 ARM64，而是使用 Java 和 Android 系统接口替代旧 JNI 边界。运行日志已确认 64 位进程，未使用 32 位模拟或翻译层。视频播放能力取决于系统解码器，没有增加通用软件解码器。

实况支持常见内嵌布局与同名配对，尚未实现苹果 Content Identifier 跨文件名配对或 `.livp` 归档处理；不能保证所有厂商样本都兼容。
