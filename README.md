# 快图怀旧版

基于快图浏览（QuickPic）4.5.2 的个人兼容修改版，保留原有相册界面，适配仅支持 64 位进程的安卓设备。非官方项目。

前往 [最新发布页](https://github.com/tiancaiProgramer/quickpic-classic/releases/latest) 下载 **QuickPicClassic-4.5.2-r2.apk**。

- 应用名称：快图怀旧版
- 显示版本：4.5.2-r2
- 本次更新日期：2026-10-28
- 内部安装编号：99999207
- 包名：`com.alensw.PicFolder`
- 最低 Android 版本：Android 7.0（API 24）
- 目标 API：28
- 已在 Android 16 / arm64 真机验证

## 版本与更新记录

`4.5.2` 表示原版基础，`r2` 表示怀旧版的第 2 次公开迭代，后续依次使用 `4.5.2-r3`、`4.5.2-r4`。每次公开更新创建独立标签和 Release，保留历史安装包；Android 内部安装编号同时递增，保证同签名版本可覆盖升级。

本次更新：修复点开图片、隐藏/显示操作栏及返回列表时的末尾位移；图片画布保持固定，操作栏继续叠加显示。详见 [更新记录](CHANGELOG.md)。

## 功能与调整

- 保留相册、按时间浏览、图片查看和原有基本操作。
- 在 64 位 Android ART 进程运行，以 Java 和系统接口替换旧的 31 个 JNI 接口，不再加载旧 32 位原生库。
- 增加 HEIC / HEIF 格式识别，解码依赖设备系统。
- 识别实况照片的内嵌视频，或同目录同名的图片与 MOV / MP4。点开后在原浏览页静音播放一次，点击 LIVE 可停止或重播。
- 保留局域网快传。
- 修复左侧导航栏展开和紫色图标；侧栏保留相册、活动、快传、设置，移除云备份及添加云账号入口。
- 主页设置与快传统一保留在左侧导航栏；查看或选择模式保留需要的上下文操作。
- 全局显示系统壁纸背景，使用黑色遮罩与浅色文字。相册、看图、设置、快传和壁纸裁剪页均适配。
- 在相册“⋮ → 背景透明度”或设置中调节透明度，拖动即时预览，应用保存、取消还原。默认透明度 40%，已有保存值保留。
- 桌面长按图标提供“快传”和“壁纸”。壁纸入口先选图和裁剪，用户确认后只设置桌面壁纸。
- 修复看图页操作栏与状态栏显隐时挖孔区避让切换造成的图片位移；固定图片画布，保留按钮安全区，稳定进入和返回缩略图的位置。
- 修复返回桌面、热启动和快速重开时的蓝色全屏图标。过渡仅让背景暂时变黑，保留内容和按钮显示，再渐变恢复已保存的透明度；快速返回单独处理缺失的系统动画回调，缩短黑底等待。
- 设置新增“关于”，通过“GitHub 更新”打开最新发布页；关于条目不显示副标题。
- 移除全量应用列表扫描及 NFC、WAKE_LOCK、CHANGE_WIFI_STATE、旧式 INSTALL_SHORTCUT 权限。
- 此前增加的 WebDAV 已移除。

## “活动”视图

“活动”对应 Moments，为本地照片的时间分组视图。默认按自然月归类，有可解析的地点时再按地点细分。优先使用系统媒体库的拍摄时间，缺失时使用文件修改时间，月份边界按手机时区计算。

## 安装与兼容

本发布包与本项目此前的兼容测试版使用相同签名，可直接覆盖安装；显示版本为 4.5.2-r2，内部安装编号为 99999207。不同签名的原版无法直接覆盖。

需要允许照片、视频和存储访问。快传使用当前已连接的 Wi-Fi，不代用户开关 Wi-Fi。

仍使用目标 API 28 的旧存储兼容路径，Android 16 可能把存储权限拆分显示为照片、视频、音频和媒体位置等项目；本次未迁移整套存储实现。没有声明 QUERY_ALL_PACKAGES，也不再调用全量应用枚举；分享菜单仍按具体分享操作查询接收应用。

这不是将原 C/C++ 核心重新编译为 ARM64，而是替换旧 JNI 边界。已确认 64 位进程，未使用 32 位模拟或翻译层。视频能力取决于系统解码器，没有增加通用软件解码器。

实况支持常见内嵌布局与同名配对，尚未实现苹果 Content Identifier 跨文件名配对或 `.livp` 归档处理；不能保证所有厂商样本都兼容。
